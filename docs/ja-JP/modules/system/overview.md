# Overview

## このモジュールでできること

Overview モジュールは、RelayGate の現在の実行状態を確認するためのページです。

ローカルプロキシ、読み込まれている機能モジュール、DNS profiles、upstream proxies、site mounts、基本的な環境情報をまとめて確認できます。

## 使う場面

RelayGate が正常に動いているか、主要な機能が読み込まれているかを確認したいときに使います。

起動直後、ルール変更後、新しい runtime 機能を有効にした後の確認にも向いています。

## 仕組み

このページは backend の live summary を読み取り、ひとつの場所に表示します。

各機能の詳細設定を行うページではありません。設定を変更する場合は、対応するモジュールページを開いてください。

## 注意点

Overview は状態確認用のページであり、詳細なトラフィック解析ツールではありません。

より細かい接続追跡や log は、別の機能または将来のページで扱われる可能性があります。
